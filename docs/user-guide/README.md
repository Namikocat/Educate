# คู่มือผู้ใช้ UniLearn Studio

## ติดตั้ง
1. ดับเบิลคลิก `UniLearn Studio_1.0.0_x64-setup.exe` (หรือไฟล์ `.msi`)
2. ทำตามขั้นตอน ไม่ต้องติดตั้ง Python หรือโปรแกรมอื่น (ถ้าเครื่องไม่มี WebView2 ตัวติดตั้งจะดาวน์โหลดให้)
3. เปิดโปรแกรมจากเมนู Start แล้วตั้งชื่อโปรไฟล์ ข้อมูลเก็บในเครื่องของคุณเท่านั้น

## การเรียน
* **บทเรียน** – เลือกหัวข้อทางซ้าย เลือกระดับคำอธิบาย (พื้นฐาน/มาตรฐาน/เชิงลึก) ดูตัวอย่างทีละขั้น ภาพจำลอง และจดบันทึกทางขวา
* **ฝึกทำโจทย์** – โหมด *มีคำแนะนำ*, *อิสระ* หรือ *ทบทวนจุดอ่อน* (ระบบเลือกหัวข้อให้) พิมพ์คำตอบ เช่น `x^2/2 + C`, `sqrt(x+1)`, `e^(2x)`, `ln|x|`, `arctan(x/3)` หรือ `diverges`
  * ช่องด้านล่างแสดงว่าระบบอ่านคำตอบของคุณอย่างไร
  * ปุ่ม คำใบ้ / แสดงขั้นถัดไป / แสดงวิธีทำทั้งหมด / โจทย์ใหม่
  * แป้นลัด: Ctrl+Enter ตรวจ, Alt+H คำใบ้, Alt+S ขั้นถัดไป, Alt+N โจทย์ใหม่
* **ศูนย์สอบ** – เลือกชุดบทที่ 5/6/7/8 หรือปลายภาค กำหนดจำนวนข้อ เวลา และ seed มีจับเวลา บันทึกอัตโนมัติ และเฉลยละเอียดหลังส่ง
* **ภาพจำลอง** – ปรับจำนวนสี่เหลี่ยม ขอบเขต มุมหมุน 3 มิติ และพิมพ์ฟังก์ชันของคุณเอง
* **ความก้าวหน้า** – ความเชี่ยวชาญรายหัวข้อ (เป็นค่าประมาณ) ข้อผิดพลาดที่พบบ่อย และคำแนะนำ
* แป้นลัดทั่วไป: Alt+1…9 เปลี่ยนหน้า, Ctrl+K ค้นหา, F11 โหมดโฟกัส

## AI Tutor (ไม่บังคับ)
ต้องติดตั้ง [Claude Code CLI](https://docs.claude.com/claude-code) และลงชื่อเข้าใช้เอง จากนั้นเปิดใน *ตั้งค่า → AI Tutor* คุณเลือกได้ว่าจะส่งข้อมูลใด
(โจทย์ เฉลยที่ตรวจแล้ว คำตอบของคุณ ขั้นที่เลือก) คำตอบจาก AI เป็นข้อมูลเสริมที่ยังไม่ผ่านการตรวจ

## ข้อมูลของฉัน
*ตั้งค่า → ส่งออกข้อมูล* บันทึกไฟล์สำรองไปที่ `Downloads\UniLearn Studio` และนำเข้าคืนได้ ระบบสำรองฐานข้อมูลอัตโนมัติวันละครั้ง
